# Product

## Background

少年野球チームがイベント連絡・出欠管理に使っている既存サイト「いくぜ！」の年間契約（5,500円）更新タイミングで、乗り換えを検討している。第一候補の TeamHub はテスト中だが、初期設定（親と子の紐付け、出欠）が分かりにくい。

## Target User

保護者（主）、指導者、選手、その他関係者。父・母がそれぞれアプリを使う。

## User Problem

- 初期設定が難しく、ドキュメントを読んでも分からない
- 親アカウントと子（選手）の関係が分かりにくい
- 出欠を誰が誰の分として回答するのかが分かりにくい

## User Goal

迷わず初期設定を終え、イベントと出欠を数タップで扱えること。

## Core Value

初期設定と出欠回答の迷いをなくし、チーム全員の出欠状況をすぐ把握できる。

## Core User Flow

0. （指導者）選手を名簿に登録し、選手ごとの招待コードを家庭に配る
1. アプリを開く
2. 招待コードと名前を入力してお子さんと紐付く
3. 今後のイベント一覧を見る
4. 子ごとの出欠をワンタップで回答（保護者自身の帯同も回答可）
5. イベント詳細で全員の出欠状況を確認

## Prototype Hypothesis

- 「招待コードを入れる」だけの初期設定であれば、説明なしで完了できる
- 選手登録を指導者に限定すれば、父・母が別々に登録しても選手が重複しない
- 出欠を「選手の出欠」と「保護者本人の参加」に分けて表示すれば、両親が使っても混乱しない
