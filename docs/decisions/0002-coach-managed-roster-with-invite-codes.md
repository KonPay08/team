# 0002. 選手名簿は指導者が管理し、家庭は招待コードで参加する

## Status

Accepted

## Context

初期設定の運用として「各家庭が自分でアカウントと選手を登録する」方式と「チーム代表が登録して招待する」方式のどちらを取るかを検討した。

家庭側が選手を自由に作成できると、父と母が別々に同じ子を登録して選手が重複し、出欠が2件に分裂する。これは顧客が TeamHub で困っている「親子の紐付けが分かりにくい」状態そのものになる。また名簿（学年・在籍）はチーム運営側が持つ情報であり、家庭側が正とは限らない。

## Decision

- Player（選手名簿）の作成は指導者のみが行う。
- 指導者は Player ごとに招待コードを発行し、家庭に配る。指導者・スタッフ用にはチーム共通コードを1つ持つ。
- 保護者・選手本人は招待コードと名前を入力して既存の Player に紐付く。参加時に Player を新規作成することはできない。
- 父・母は同じ招待コードを使うため、同じ Player に複数の User が紐付き、出欠は1件のまま共有される。

## Consequences

- 家庭側の初期設定は「コードと名前の入力」のみになり、親子の紐付けを利用者が考える必要がなくなる。
- 名簿の誤りは指導者が直す運用になり、指導者の初期作業（選手登録とコード配布）が増える。
- 招待コードの配布・有効期限・再発行の運用ルールが必要になる（未決定）。
- Prototypeではコードを画面表示するのみで、商品化時は招待リンクとログインに置き換える想定。
